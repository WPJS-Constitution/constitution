# T02 — Voting

**Topic ID:** T02  
**Topic version:** BASE  
**Status:** Draft in progress; not closed for a Constitution edition  
**Approval status:** Proposal for discussion; not formally approved

## Origin and intended outcome

This BASE records the first independently developed starting point for the Voting topic. It is intended to make voting electronic, identifiable as a clear process, connected to membership, private in each member's choice, transparent in its aggregate count, and open only while further votes could change the result.

No wording, rule, structure, or decision is inherited from a previous ccc.

## Design notes (not proposed ccc clauses)

- A proxy was considered. It is not included because electronic voting allows each member to cast their own vote without attending a meeting.
- The option with the highest count wins. A strict majority is not required. This makes the closing test about whether any uncast vote could change which option has the highest count.
- The voter roll is intended to come directly from the members-in-good-standing list. The Membership topic must define that status.
- Voting is a duty, but the vote may close before every member responds if remaining votes can no longer change which option has the highest count.
- Ballot privacy and a live aggregate count must both be supported: members can be confirmed as having voted, but their selected option is not linked to them or disclosed.
- The Constitution should set durable voting principles; the specific electronic tool, reminders, access controls, and operational safeguards belong in policy.

## Open design questions

- Who can inspect the voter roll, and whether it is available only to members or more widely.
- Whether members can see which people have voted, separately from the anonymous live count.
- How members can remind others to vote without exposing contact details or ballot choices.
- How the electronic system will verify eligibility and prevent duplicate votes while preserving ballot privacy.
- How to support members who need help accessing the electronic system while preserving their own choice.
- The exact calculation and display of the live count and the mathematical point at which uncast votes can no longer change the highest-count option.

These questions do not prevent this BASE from recording the agreed starting principles. They must be resolved before the Topic is closed for a Constitution edition.
